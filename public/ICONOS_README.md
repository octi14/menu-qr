# Iconos para Manifest.json

Este directorio necesita los siguientes iconos para que el manifest.json funcione correctamente:

## Iconos Requeridos

- `icon-192.png` - 192x192 píxeles
- `icon-512.png` - 512x512 píxeles

## Especificaciones

- Formato: PNG
- Fondos: Transparentes o sólidos (recomendado sólido para mejor visibilidad)
- Tema: Debe representar el logo/branding de FoodLand
- Colores: Deben verse bien tanto en fondos claros como oscuros

## Generación

Los iconos pueden generarse desde:
- Un logo existente de FoodLand
- Herramientas online como https://realfavicongenerator.net/
- Herramientas de diseño (Figma, Photoshop, etc.)

## Nota Temporal

Mientras se crean los iconos definitivos, el manifest.json seguirá funcionando pero los navegadores mostrarán un icono por defecto o un placeholder.
